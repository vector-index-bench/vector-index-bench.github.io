# VIBE result files

These Parquet files are generated by VIBE's [`export_results.py`](https://github.com/vector-index-bench/vibe/blob/main/export_results.py).

| File | Row represents | Columns |
| --- | --- | --- |
| `summary.parquet` | One dataset/algorithm/configuration/`k` result | `k`, `dataset`, `algorithm`, `params`, `qps`, `recall`, `build_time`, `index_size` |
| `*__detail.parquet` | One query result for the dataset named by the file | `dataset`, `query_index`, `k`, `algorithm`, `params`, `time`, `recall`, `build_time`, `index_size` |
| `stats.parquet` | One query's dataset-difficulty statistics | `dataset`, `query_index`, `rc1`, `rcdim1`, `lid10`, `rc10`, `rcdim10`, `lid100`, `rc100`, `rcdim100` |
| `data-info.parquet` | One dataset | `dataset`, `n`, `dimensions` |
| `data-pca-mahalanobis.parquet` | One sampled training vector or test query used by the dataset visualization | `dataset`, `part`, `x`, `y`, `mahalanobis_distance_to_data` |

## Column definitions

- `n` is the number of indexed/training vectors, and `dimensions` is their dimensionality.
- `qps` is the best measured queries/second; `time` is per-query latency in seconds. `build_time` is in seconds and `index_size` is measured index memory in KiB.
- `recall` is Recall@`k` in `[0, 1]`: per-query in detail files and averaged over queries in `summary.parquet`.
- `rcK` is relative contrast at `K` (mean query-to-data distance divided by the `K`th-neighbor distance); `rcdimK` is the corresponding local relative-contrast dimension, and `lidK` is local intrinsic dimensionality estimated from the first `K` neighbors.
- `part` is `train` or `test`; `x` and `y` are the first two PCA coordinates after feature standardization, and `mahalanobis_distance_to_data` measures distance from the training-data distribution.
